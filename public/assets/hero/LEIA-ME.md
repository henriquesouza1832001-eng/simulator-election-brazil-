# Imagens de abertura (herói)

O jogo já traz uma arte padrão em duas cores (a Esplanada em SVG). Para usar uma imagem real, coloque aqui arquivos WebP com este nome:

- `hero-painel-calmo.webp`  (tudo bem)
- `hero-painel-tenso.webp`  (sinais de alerta)
- `hero-painel-crise.webp`  (crise em andamento)

Formato 21:9, 2560x1100, até 250 KB. Se o arquivo existir, ele substitui a arte; se não existir, a arte padrão continua. Não precisa mexer em código.
O pedido de geração de cada imagem está em `docs/DIRECAO_VISUAL.md`, seção 8.
